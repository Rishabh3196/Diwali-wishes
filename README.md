🪔 Happy Diwali — Personalized Festive Website

A beautiful, personalized Diwali greeting website created using HTML, CSS, and JavaScript. It combines festive visuals, soulful music, and heartfelt messages to make Diwali wishes more special for friends and loved ones.

✨ Features

Personalized Greetings: Display a receiver's name dynamically through URL parameters.

Soulful Music: Includes an audio player to enjoy music while viewing the greeting.

Festive Decorations: Features Diwali diyas, decorative jhalar, and festive imagery.

Lakshmi and Ganesh Section: Includes devotional imagery and a Diwali blessing message.

Heartfelt Wishes: Displays personalized messages expressing happiness, positivity, and gratitude.

Dynamic Sender Name: Shows the sender's name at the bottom of the website.

Google Fonts: Uses custom fonts to enhance the website's visual appearance.

🛠️ Technologies Used

HTML5

CSS3

JavaScript

Google Fonts

HTML Audio Element

🚀 How to Run the Project

Clone or download this repository.

Open the project folder in Visual Studio Code.

Install the Live Server extension if you haven't already.

Right-click index.html and select Open with Live Server.

View your personalized Diwali greeting in the browser.

🎁 Personalize Your Greeting

The website reads the receiver's and sender's names from URL parameters.

Personalize Your Greeting

The website reads the receiver's and sender's names from URL parameters.

Example:

http://127.0.0.1:5500/index.html?receiver=Friend&sender=Rishabh%20Raj

receiver — Name of the person receiving the greeting.

sender — Name of the person sending the greeting.

If the sender parameter is not provided, the website displays Rishabh Raj by default.
